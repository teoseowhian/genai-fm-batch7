# GenAI for Facilities Management – Batch 7

Tabs: **Learning needs** · **Vibe & agentic coding** · **Class materials** (prompts from the class Padlet) · **Batch photos** (link to the shared album).

An interactive page summarising what Batch 7 (23–25 Nov 2026) of the *GenAI for Facilities Management* course wants to learn: learning themes, function groups, starting AI level, a function × theme heatmap, lecturer focus lists and a searchable needs directory.

**Anonymised:** no participant names, organisations, emails or phone numbers. Each participant appears only as an ID (P01–P23) with their function group, AI level, stated challenge and what they want to bring back.

## Files

| File | What it is |
|---|---|
| `learn.html` | Interactive lesson on vibe coding vs agentic coding, with a quick tutor, demo, quiz and exercise |
| `index.html` | The page (charts use d3 v7 from cdnjs) |
| `data.js` | The anonymised needs data the page reads |
| `batch7_needs.csv` | The same data as a CSV |
| `render.yaml` | Render Blueprint to host it as a free static site |

## Use it

- Open `index.html` in a browser, or turn on **GitHub Pages** (Settings → Pages → Deploy from branch `main`, folder `/`).
- Or deploy on Render: **New → Blueprint**, pick this repository.
