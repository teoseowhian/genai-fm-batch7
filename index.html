Learning skills · Muse personal agent

Learn Muse in 6 skills

Muse is a personal AI agent: it has its own computer, remembers your context, can connect to Gmail and Calendar, runs tasks on a schedule and uses websites for you. Work through the skills in order. Each one is linked to a Batch 7 need and has a prompt to try.

Safe use: use your company's approved tools for work data. Don't paste tenant personal data or confidential contracts into a personal account. Connect only the apps a task needs, and check every draft before it is sent. Muse asks before it buys anything; keep it that way.

Agentic · build an assistant

Copilot agent: Fire Safety Inspection & Compliance Assistant

Build an agent in Microsoft 365 Copilot (or a Gem / Claude Project) that uses the SCDF Fire Code as its knowledge source. The agent works through a short conversation:

  1. Understand the task: building type, area or fire-safety system, purpose of the inspection, site photos or notes.
  2. Give practical guidance: explain the Fire Code in plain English, cite clauses that can be checked, make inspection checklists, ask follow-up questions.
  3. Recommend actions: for each issue, the observation, Fire Code clause, risk, priority (High / Medium / Low), corrective action and responsible party.
  4. Produce FM outputs: inspection checklist, preliminary compliance review, corrective-action register, draft contractor work order.

Guardrail: it supports inspection preparation, not formal certification. It drafts for human review and never claims to issue work orders or notify people.
